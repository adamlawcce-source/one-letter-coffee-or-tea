A tiny Node 22 program for the make.fun bounty
[One Letter: Coffee or Tea](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0).

`main.ts` writes one letter to `/output/entry.txt`: **A** — for coffee.
Coffee wins the morning: the first cup is the day's opening move, and
everything after it is just follow-through. No network, no randomness,
no input — the same letter on every run.

## Run it

```sh
node main.ts
```
